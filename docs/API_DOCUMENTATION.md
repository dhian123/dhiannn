# SiNusa API Documentation\n\n## Overview\n\nSiNusa (Santri & Wali Santri Information System) is a comprehensive Islamic boarding school management system that provides mobile and web interfaces for managing students, finances, attendance, grades, and more.\n\n## Base URL\n\n```\nDevelopment: http://localhost:3000/api/v1\nProduction: https://api.sinusa.com/v1\n```\n\n## Authentication\n\nThe API uses JWT (JSON Web Tokens) for authentication. Include the token in the Authorization header:\n\n```\nAuthorization: Bearer <your_jwt_token>\n```\n\n## API Endpoints\n\n### Authentication\n\n#### POST /auth/login\nLogin with username/email/phone and password.\n\n**Request Body:**\n```json\n{\n  \"identifier\": \"user@example.com\",\n  \"password\": \"password123\",\n  \"deviceId\": \"optional-device-id\"\n}\n```\n\n**Response:**\n```json\n{\n  \"status\": \"success\",\n  \"message\": \"Login successful\",\n  \"data\": {\n    \"user\": {\n      \"id\": \"uuid\",\n      \"username\": \"user123\",\n      \"email\": \"user@example.com\",\n      \"role\": \"SANTRI\"\n    },\n    \"accessToken\": \"jwt_token\",\n    \"refreshToken\": \"refresh_token\",\n    \"expiresIn\": 86400\n  }\n}\n```\n\n#### POST /auth/otp/send\nSend OTP to phone number or email.\n\n**Request Body:**\n```json\n{\n  \"identifier\": \"+628123456789\"\n}\n```\n\n#### POST /auth/otp/verify\nVerify OTP and login.\n\n**Request Body:**\n```json\n{\n  \"identifier\": \"+628123456789\",\n  \"otp\": \"123456\",\n  \"deviceId\": \"optional-device-id\"\n}\n```\n\n#### POST /auth/refresh\nRefresh access token.\n\n**Request Body:**\n```json\n{\n  \"refreshToken\": \"refresh_token\"\n}\n```\n\n#### POST /auth/logout\nLogout user (requires authentication).\n\n### User Management\n\n#### GET /users/profile\nGet current user profile (requires authentication).\n\n**Response:**\n```json\n{\n  \"status\": \"success\",\n  \"data\": {\n    \"user\": {\n      \"id\": \"uuid\",\n      \"username\": \"user123\",\n      \"email\": \"user@example.com\",\n      \"firstName\": \"John\",\n      \"lastName\": \"Doe\",\n      \"role\": \"SANTRI\",\n      \"santriProfile\": {\n        \"santriNumber\": \"20240001\",\n        \"currentClass\": \"Tsanawiyah 1\"\n      }\n    }\n  }\n}\n```\n\n#### PUT /users/profile\nUpdate user profile (requires authentication).\n\n### Santri Management\n\n#### GET /santri\nGet santri data (requires authentication).\n\n#### GET /santri/balance\nGet pocket money balance.\n\n**Response:**\n```json\n{\n  \"status\": \"success\",\n  \"data\": {\n    \"balance\": 150000.00,\n    \"currency\": \"IDR\"\n  }\n}\n```\n\n#### GET /santri/savings\nGet santri savings.\n\n### Payment Management\n\n#### POST /payments/topup\nCreate top-up payment.\n\n**Request Body:**\n```json\n{\n  \"amount\": 100000,\n  \"paymentMethod\": \"BANK_TRANSFER\"\n}\n```\n\n#### GET /payments/bills\nGet bills and installments.\n\n**Query Parameters:**\n- `status`: Filter by bill status\n- `period`: Filter by period (YYYY-MM)\n- `page`: Page number (default: 1)\n- `limit`: Items per page (default: 20)\n\n#### GET /payments/history\nGet payment history.\n\n**Query Parameters:**\n- `type`: Filter by transaction type\n- `category`: Filter by category\n- `page`: Page number\n- `limit`: Items per page\n\n### Attendance Management\n\n#### GET /attendance\nGet attendance records.\n\n**Query Parameters:**\n- `startDate`: Filter from date (YYYY-MM-DD)\n- `endDate`: Filter to date (YYYY-MM-DD)\n- `type`: Filter by attendance type\n- `page`: Page number\n- `limit`: Items per page\n\n#### GET /attendance/summary\nGet attendance summary.\n\n**Query Parameters:**\n- `academicYear`: Academic year (YYYY/YYYY)\n- `semester`: Semester (1 or 2)\n\n### Grades Management\n\n#### GET /grades\nGet grades and assessments.\n\n**Query Parameters:**\n- `academicYear`: Academic year\n- `semester`: Semester\n- `subjectId`: Filter by subject\n- `page`: Page number\n- `limit`: Items per page\n\n#### GET /grades/report-card\nGet report card.\n\n**Query Parameters:**\n- `academicYear`: Academic year\n- `semester`: Semester\n\n### File Upload\n\n#### POST /upload/image\nUpload image file.\n\n**Request:** Multipart form data with `file` field\n\n#### POST /upload/document\nUpload document file.\n\n**Request:** Multipart form data with `file` field\n\n## Error Responses\n\nAll API endpoints return consistent error responses:\n\n```json\n{\n  \"status\": \"error\",\n  \"message\": \"Error description\",\n  \"details\": {\n    \"field\": \"Validation error details\"\n  }\n}\n```\n\n### HTTP Status Codes\n\n- `200` - Success\n- `201` - Created\n- `400` - Bad Request\n- `401` - Unauthorized\n- `403` - Forbidden\n- `404` - Not Found\n- `422` - Validation Error\n- `429` - Too Many Requests\n- `500` - Internal Server Error\n\n## Rate Limiting\n\nAPI endpoints are rate limited:\n\n- Authentication endpoints: 5 requests per 15 minutes\n- General API endpoints: 100 requests per 15 minutes\n- Payment endpoints: 10 requests per hour\n- OTP endpoints: 1 request per minute\n\nRate limit headers are included in responses:\n\n```\nX-RateLimit-Limit: 100\nX-RateLimit-Remaining: 95\nX-RateLimit-Reset: 2024-01-01T12:00:00Z\n```\n\n## Pagination\n\nList endpoints support pagination:\n\n```json\n{\n  \"status\": \"success\",\n  \"data\": {\n    \"items\": [...],\n    \"pagination\": {\n      \"page\": 1,\n      \"limit\": 20,\n      \"total\": 100,\n      \"pages\": 5\n    }\n  }\n}\n```\n\n## WebSocket Events\n\nReal-time updates are available via WebSocket connection:\n\n### Connection\n```javascript\nconst socket = io('ws://localhost:3000', {\n  auth: {\n    token: 'your_jwt_token'\n  }\n});\n```\n\n### Events\n- `notification` - New notifications\n- `balance_update` - Balance changes\n- `transaction_update` - Transaction status updates\n- `payment_update` - Payment status updates\n- `grade_update` - New grades published\n- `announcement` - New announcements\n\n## SDK and Examples\n\n### JavaScript/TypeScript\n```javascript\nconst api = axios.create({\n  baseURL: 'http://localhost:3000/api/v1',\n  headers: {\n    'Authorization': `Bearer ${token}`\n  }\n});\n\n// Login\nconst login = await api.post('/auth/login', {\n  identifier: 'user@example.com',\n  password: 'password123'\n});\n\n// Get balance\nconst balance = await api.get('/santri/balance');\n```\n\n### Flutter/Dart\n```dart\nclass SiNusaAPI {\n  static const String baseUrl = 'http://localhost:3000/api/v1';\n  \n  static Future<Map<String, dynamic>> login(String identifier, String password) async {\n    final response = await http.post(\n      Uri.parse('$baseUrl/auth/login'),\n      headers: {'Content-Type': 'application/json'},\n      body: jsonEncode({\n        'identifier': identifier,\n        'password': password,\n      }),\n    );\n    \n    return jsonDecode(response.body);\n  }\n}\n```\n\n## Testing\n\nUse the interactive
