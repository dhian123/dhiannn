# SiNusa Deployment Guide\n\n## Overview\n\nThis guide covers deploying the SiNusa application in various environments, from development to production.\n\n## Prerequisites\n\n- Docker and Docker Compose\n- Node.js 18+ (for local development)\n- PostgreSQL 14+\n- Redis 6+\n- Flutter SDK 3.0+ (for mobile app)\n\n## Quick Start with Docker\n\n### Development Environment\n\n1. **Clone the repository:**\n```bash\ngit clone https://github.com/sinusa/sinusa-app.git\ncd sinusa-app\n```\n\n2. **Set up environment variables:**\n```bash\ncp backend/.env.example backend/.env\n# Edit backend/.env with your configuration\n```\n\n3. **Start the development environment:**\n```bash\ndocker-compose --profile dev up -d\n```\n\n4. **Access the services:**\n- API: http://localhost:3000\n- API Documentation: http://localhost:3000/api-docs\n- Database Admin: http://localhost:8080\n- Redis Admin: http://localhost:8081\n\n### Production Environment\n\n1. **Set up production environment variables:**\n```bash\ncp backend/.env.example backend/.env.production\n# Configure production settings\n```\n\n2. **Build and deploy:**\n```bash\ndocker-compose -f docker-compose.yml -f docker-compose.prod.yml up -d\n```\n\n## Manual Installation\n\n### Backend API Setup\n\n1. **Install dependencies:**\n```bash\ncd backend\nnpm install\n```\n\n2. **Set up database:**\n```bash\n# Create PostgreSQL database\npsql -U postgres -c \"CREATE DATABASE sinusa_dev;\"\n\n# Run migrations\nnpm run db:migrate\nnpm run db:seed\n```\n\n3. **Start Redis:**\n```bash\nredis-server\n```\n\n4. **Start the API server:**\n```bash\nnpm run dev\n```\n\n### Mobile App Setup\n\n1. **Install Flutter dependencies:**\n```bash\ncd mobile\nflutter pub get\n```\n\n2. **Generate code:**\n```bash\nflutter packages pub run build_runner build\n```\n\n3. **Run the app:**\n```bash\nflutter run\n```\n\n### Web Dashboard Setup\n\n1. **Install dependencies:**\n```bash\ncd web-dashboard\nnpm install\n```\n\n2. **Start development server:**\n```bash\nnpm run dev\n```\n\n## Environment Configuration\n\n### Backend Environment Variables\n\nCreate `backend/.env` with the following variables:\n\n```bash\n# Environment\nNODE_ENV=production\nPORT=3000\nLOG_LEVEL=info\n\n# Database\nDB_HOST=your-db-host\nDB_PORT=5432\nDB_NAME=sinusa_prod\nDB_USERNAME=your-db-user\nDB_PASSWORD=your-db-password\nDATABASE_URL=postgresql://user:pass@host:port/db\n\n# Redis\nREDIS_HOST=your-redis-host\nREDIS_PORT=6379\nREDIS_PASSWORD=your-redis-password\n\n# Security\nJWT_SECRET=your-super-secret-jwt-key-64-characters-long\nJWT_REFRESH_SECRET=your-refresh-secret-key-64-characters-long\nENCRYPTION_KEY=your-32-character-encryption-key\n\n# External Services\nTWILIO_ACCOUNT_SID=your-twilio-sid\nTWILIO_AUTH_TOKEN=your-twilio-token\nTWILIO_PHONE_NUMBER=+1234567890\n\nSMTP_HOST=smtp.gmail.com\nSMTP_PORT=587\nSMTP_USER=your-email@gmail.com\nSMTP_PASS=your-app-password\n\n# Payment Gateways\nMIDTRANS_SERVER_KEY=your-midtrans-server-key\nMIDTRANS_CLIENT_KEY=your-midtrans-client-key\nXENDIT_SECRET_KEY=your-xendit-secret-key\n\n# File Storage\nAWS_ACCESS_KEY_ID=your-aws-key\nAWS_SECRET_ACCESS_KEY=your-aws-secret\nAWS_S3_BUCKET=your-s3-bucket\n\n# Monitoring\nSENTRY_DSN=your-sentry-dsn\n```\n\n### Mobile App Configuration\n\nUpdate `mobile/lib/core/constants/app_constants.dart`:\n\n```dart\nstatic const String baseUrl = 'https://api.sinusa.com/v1';\nstatic const String socketUrl = 'wss://api.sinusa.com';\n```\n\n## Database Setup\n\n### PostgreSQL Setup\n\n1. **Install PostgreSQL:**\n```bash\n# Ubuntu/Debian\nsudo apt update\nsudo apt install postgresql postgresql-contrib\n\n# CentOS/RHEL\nsudo yum install postgresql-server postgresql-contrib\n```\n\n2. **Create database and user:**\n```sql\nCREATE DATABASE sinusa_prod;\nCREATE USER sinusa_user WITH ENCRYPTED PASSWORD 'secure_password';\nGRANT ALL PRIVILEGES ON DATABASE sinusa_prod TO sinusa_user;\n```\n\n3. **Configure PostgreSQL:**\nEdit `/etc/postgresql/14/main/postgresql.conf`:\n```\nlisten_addresses = '*'\nmax_connections = 200\nshared_buffers = 256MB\neffective_cache_size = 1GB\n```\n\nEdit `/etc/postgresql/14/main/pg_hba.conf`:\n```\nhost    sinusa_prod    sinusa_user    0.0.0.0/0    md5\n```\n\n### Redis Setup\n\n1. **Install Redis:**\n```bash\n# Ubuntu/Debian\nsudo apt install redis-server\n\n# CentOS/RHEL\nsudo yum install redis\n```\n\n2. **Configure Redis:**\nEdit `/etc/redis/redis.conf`:\n```\nbind 0.0.0.0\nrequirepass your_redis_password\nmaxmemory 512mb\nmaxmemory-policy allkeys-lru\n```\n\n## Load Balancing & Scaling\n\n### Nginx Configuration\n\nCreate `/etc/nginx/sites-available/sinusa`:\n\n```nginx\nupstream sinusa_backend {\n    server 127.0.0.1:3000;\n    server 127.0.0.1:3001;\n    server 127.0.0.1:3002;\n}\n\nserver {\n    listen 80;\n    server_name api.sinusa.com;\n    return 301 https://$server_name$request_uri;\n}\n\nserver {\n    listen 443 ssl http2;\n    server_name api.sinusa.com;\n\n    ssl_certificate /etc/ssl/certs/sinusa.crt;\n    ssl_certificate_key /etc/ssl/private/sinusa.key;\n    ssl_protocols TLSv1.2 TLSv1.3;\n    ssl_ciphers ECDHE-RSA-AES256-GCM-SHA512:DHE-RSA-AES256-GCM-SHA512;\n\n    client_max_body_size 10M;\n\n    location / {\n        proxy_pass http://sinusa_backend;\n        proxy_http_version 1.1;\n        proxy_set_header Upgrade $http_upgrade;\n        proxy_set_header Connection 'upgrade';\n        proxy_set_header Host $host;\n        proxy_set_header X-Real-IP $remote_addr;\n        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;\n        proxy_set_header X-Forwarded-Proto $scheme;\n        proxy_cache_bypass $http_upgrade;\n        proxy_connect_timeout 60s;\n        proxy_send_timeout 60s;\n        proxy_read_timeout 60s;\n    }\n\n    location /socket.io/ {\n        proxy_pass http://sinusa_backend;\n        proxy_http_version 1.1;\n        proxy_set_header Upgrade $http_upgrade;\n        proxy_set_header Connection \"upgrade\";\n        proxy_set_header Host $host;\n        proxy_set_header X-Real-IP $remote_addr;\n        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;\n        proxy_set_header X-Forwarded-Proto $scheme;\n    }\n\n    location /uploads/ {\n        alias /var/www/sinusa/uploads/;\n        expires 1y;\n        add_header Cache-Control \"public, immutable\";\n    }\n}\n```\n\n### PM2 Process Management\n\nCreate `ecosystem.config.js`:\n\n```javascript\nmodule.exports = {\n  apps: [{\n    name: 'sinusa-api',\n    script: './src/index.js',\n    instances: 'max',\n    exec_mode: 'cluster',\n    env: {\n      NODE_ENV: 'production',\n      PORT: 3000\n    },\n    error_file: './logs/err.log',\n    out_file: './logs/out.log',\n    log_file: './logs/combined.log',\n    time: true,\n    max_memory_restart: '1G',\n    node_args: '--max-old-space-size=1024'\n  }]\n};\n```\n\nStart with PM2:\n```bash\nnpm install -g pm2\npm2 start ecosystem.config.js\npm2 save\npm2 startup\n```\n\n## SSL/TLS Configuration\n\n### Let's Encrypt SSL\n\n```bash\n# Install Certbot\nsudo apt install certbot python3-certbot-nginx\n\n# Get +%Y%m%d_%H%M%S)\nBACKUP_DIR=\"/backup/postgresql\"\nDB_NAME=\"sinusa_prod\"\nDB_USER=\"sinusa_user\"\n\nmkdir -p $BACKUP_DIR\n\npg_dump -h localhost -U $DB_USER -d $DB_NAME | gzip > $BACKUP_DIR/sinusa_$DATE.sql.gz\n\n# Keep only last 30 days of backups\nfind $BACKUP_DIR -name \"sinusa_*.sql.gz\" -mtime +30 -delete\n\n# Upload to S3\naws s3 cp $BACKUP_DIR/sinusa_$DATE.sql.gz s3://sinusa-backups/database/\n```\n\n### File Backup\n\n```bash\n#!/bin/bash\n# backup-files.sh\nDATE=$(date +%Y%m%d_%H%M%S)\nBACKUP_DIR=\"/backup/files\"\nUPLOADS_DIR=\"/var/www/sinusa/uploads\"\n\nmkdir -p $BACKUP_DIR\n\ntar -czf $BACKUP_DIR/uploads_$DATE.tar.gz -C $UPLOADS_DIR .\n\n# Upload to S3\naws s3 cp $BACKUP_DIR/uploads_$DATE.tar.gz s3://sinusa-backups/files/\n```\n\n### Automated Backups\n\n```bash\n# Add to crontab\n0 2 * * * /path/to/backup-db.sh\n0 3 * * * /path/to/backup-files.sh\n```\n\n## Performance Optimization\n\n### Database Optimization\n\n```sql\n-- Create indexes for frequently queried columns\nCREATE INDEX CONCURRENTLY
